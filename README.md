# Semana de Tecnologia e Cultura

Página simples feita para a atividade de CSS do IFCE Campus Maranguape. Contém informações sobre o evento, programação, atividades e inscrições.

Foi desenvolvida com HTML e CSS interno, praticando cores, fontes, espaçamentos, bordas e arredondamentos. A programação é ilustrativa.

Para visualizar, abra o arquivo `index.html` no navegador.
